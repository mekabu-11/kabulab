# ユーザーマニュアル

## このアプリでできること

このアプリは、食事・体調・体重・筋トレを記録し、太りにくさや胃腸不調の傾向を見つけるための生活改善アプリです。

医療診断を行うものではありません。症状が強い場合や長引く場合は、医療機関への相談をおすすめします。

## ホーム

ホームでは、今日の摂取カロリー、目標カロリー、あと足したいカロリーを確認できます。

AIからの一言提案では、今日の記録をもとに、胃腸に負担をかけにくい追加食の候補が表示されます。

## 食事を記録する

1. ホームの「食事」ボタンを押す
2. 写真を選ぶ、または食事内容をテキストで入力する
3. 必要ならメモを入れる
4. AI解析を実行する
5. 推定された食事名、kcal、PFCを確認する
6. 違うところを修正する
7. 保存する

AI推定は目安です。量や材料が違う場合は、自分で修正してください。

## 体調を記録する

1. ホームの「体調」ボタンを押す
2. 症状を選ぶ
3. 発生時間を入力する
4. メモがあれば入力する
5. 保存する

選べる症状:

- 問題なし
- 下痢
- 便秘
- お腹の張り
- 胃もたれ
- 吐き気

## 注意が必要な症状

以下に当てはまる場合、アプリは医療機関への相談を促します。

- 血便
- 激しい腹痛
- 水分が取れない
- 高熱
- 急激な体重減少
- 下痢が長期間続く
- 嘔吐が続く

## 体重を記録する

1. ホームの「体重」ボタンを押す
2. 体重を入力する
3. 日付を選ぶ
4. メモがあれば入力する
5. 保存する

体重は日ごとの変動があります。1日の増減ではなく、数週間の傾向を見るために使います。

## 筋トレを記録する

1. 記録画面から筋トレ記録を開く
2. 種目名を入れる
3. 時間と強度を選ぶ
4. メモがあれば入力する
5. 保存する

MVPでは簡易記録です。重量やセット数の細かい管理は今後追加します。

## 分析を見る

分析画面では、直近7日間の食事、体調、体重、筋トレから以下を確認できます。

- 食事傾向
- 体調傾向
- 怪しい原因候補
- 今週試す改善案
- 増量ペースの確認

AIの提案は断定ではありません。小さく試して、自分の体調ログで確認するためのヒントとして使ってください。
