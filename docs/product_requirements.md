# 太れない人向け AI増量コーチアプリ MVP 要件定義

## 目的

太れない人・小食・胃腸が弱い人が、食事・体調・体重・筋トレ記録をもとに、自分に合った無理のない増量方法を見つけるための生活改善アプリを作る。

本アプリは医療診断ではなく、日々の記録と傾向把握を支援する。AIは断定せず、「可能性」「傾向」「試す価値がある小さな改善案」として提案する。

## 想定ユーザー

- 太りたいが体重が増えにくい人
- 小食で一度に多く食べられない人
- 筋トレ初心者
- 食後にお腹を壊しやすい人
- 乳糖不耐性、胃弱、脂質が重いなど食事選びが難しい人
- 初期ユーザーは開発者本人

## MVP の成功条件

- 食事、体調、体重、筋トレを軽く記録できる
- 食事写真またはテキストから、AIがざっくり栄養推定を出せる
- AI推定結果をユーザーが必ず修正できる
- 直近7日間のログから、増量と胃腸負担に関する傾向を表示できる
- 危険症状の記録時に、医療機関への相談を促す導線を表示できる

## MVP スコープ

### 含める機能

- Supabase Auth によるログイン
- 食事記録
- 体調記録
- 体重記録
- 簡易筋トレ記録
- AI食事解析
- AI傾向分析
- 安全アラート表示
- 直近7日間の分析画面

### MVP では含めない機能

- 医療診断
- 医師や管理栄養士との相談
- 厳密な栄養計算
- バーコードスキャン
- 外部ウェアラブル連携
- SNS機能
- 有料課金
- 複雑なトレーニングプログラム生成

## 主要ユースケース

### 食事を記録する

1. ユーザーが食事写真を選ぶ、またはテキストで食事内容を入力する
2. 任意でメモを追加する
3. AI解析を実行する
4. 推定された食事名、kcal、PFC、胃腸負担候補を確認する
5. ユーザーが必要に応じて修正する
6. 保存する

### 体調を記録する

1. ユーザーが症状をワンタップで選ぶ
2. 発生時間を入力する
3. メモを入力する
4. 危険症状が含まれる場合は受診相談の案内を表示する
5. 保存する

### 分析を見る

1. ユーザーが分析画面を開く
2. 直近7日間の食事、体調、体重、筋トレログを取得する
3. AIが傾向と改善案を生成する
4. 断定を避けた表現で、怪しい原因候補と次に試す小さな行動を表示する

## 機能要件

### 食事記録

- 写真アップロードができる
- テキスト入力ができる
- 食事時間を保存できる
- 推定カロリー、タンパク質、脂質、炭水化物を保存できる
- 胃腸に負担がありそうな要素を保存できる
- AI推定結果をユーザーが修正できる
- AI推定かユーザー修正かを区別できる

### 体調記録

- 下痢、便秘、お腹の張り、胃もたれ、吐き気、問題なしを選べる
- 複数症状を同時に選べる
- 発生時間を保存できる
- メモを保存できる
- 危険症状を選択または記述した場合に受診相談の案内を出す

### 体重記録

- 日付ごとの体重を保存できる
- メモを保存できる
- 同日の重複記録を許容するか、最新記録として扱うかをDB制約で決める

MVPでは、同一ユーザー・同一日付に1件を推奨する。

### 筋トレ記録

- 実施日を保存できる
- 種目名を保存できる
- 時間を保存できる
- 強度を保存できる
- メモを保存できる

### AI分析

- 直近7日間の傾向を分析できる
- 食事と体調不良の時間的な近さを考慮できる
- 相性が悪そうな食材候補を表示できる
- 食事量を増やしやすいタイミングを提案できる
- 今日足すとよさそうな食事案を提案できる
- 増量ペースへのコメントを表示できる
- 次に試す小さな改善アクションを提示できる

## 非機能要件

- 入力負担を少なくする
- スマートフォンで片手操作しやすい
- AI解析は失敗しても手動記録できる
- Supabase Row Level Security を有効にし、ユーザーは自分のデータだけを読める
- 食事写真は Supabase Storage に保存する
- OpenAI APIキーはアプリ側に置かず、Supabase Edge Functions から呼び出す

## セーフティ要件

以下の記録がある場合、アプリ内で医療機関への相談を促す。

- 血便
- 激しい腹痛
- 水分が取れない
- 高熱
- 急激な体重減少
- 下痢が長期間続く
- 嘔吐が続く

表示文例:

> 生活記録だけでは判断が難しい症状が含まれています。症状が強い、長引く、水分が取れない場合は、早めに医療機関へ相談してください。

## AI 表現ルール

### NG

- 牛乳が原因です
- 乳糖不耐症です
- この食材をやめれば治ります

### OK

- 牛乳やホエイを摂った日の翌朝にお腹を壊す記録が多いため、乳製品が影響している可能性があります。
- 今週は豆乳に置き換えて様子を見るとよさそうです。
- 症状が続く場合は医療機関への相談を推奨します。
